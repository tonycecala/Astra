# Astra Dark Pattern Guardrails

## Absolute Rules

- No fake scarcity.
- No guilt-based streaks.
- No hidden data collection.
- No paywall before value.
- No contact upload before explicit trust and utility.
- No variable reward loops that encourage compulsive checking.
- No astrology fear copy to force purchase.
- No destructive actions without undo or confirmation.
- No personalization that cannot be explained or controlled.

## Astra Ethical Translation

The playbook contains many useful behavioral patterns. Astra must use them as **clarity tools**, not extraction tools.

| Commercial Pattern | Astra-Safe Translation |
|---|---|
| Gamification | Meaningful progress rituals |
| Variable reward | Gentle novelty and wonder |
| Paywall | Next chapter after value |
| Scarcity | Real enrollment or launch windows only |
| Contact bridge | Optional manual sharing first |
| Habit formation | Chosen ritual, not compulsion |
| Personalization | User-guided relevance |
| Effort moat | User-owned Library and exportable archive |

## Product Review Question

Before shipping any retention or conversion feature, ask:

> Would this still feel respectful if explained plainly to the user?

If no, do not ship.
