# Astra Applicability Matrix

## Critical: Implement Deliberately

| Pattern | Why It Matters |
|---|---|
| Time to Value | Determines whether new Explorers feel immediate relevance. |
| Sandbox Experience | Lets people feel Astra before account creation. |
| Discovery | Composer’s core purpose. |
| Personalisation | Makes Astra feel irreplaceable. |
| Progressive Disclosure | Keeps astrology depth from overwhelming beginners. |
| Empty States | Prevents dead screens in Library, Allies, Gifts. |
| Success Moments | Turns progress into ceremony. |
| Value Replay | Makes return feel like continuation. |
| Effort Moat | Library becomes switching cost through meaningful artifacts. |
| Pattern Alignment | Keeps UX obvious while the content stays magical. |
| Fail Safe | Protects trust and reduces fear. |
| Deep Link | Required for notification/email/widget loops. |
| JTBD Copywriting | Converts UI labels into forward motion. |
| Trust Building | Mandatory for AI + astrology + personal data. |

## High: Strong Fit

| Pattern | Best Use |
|---|---|
| Setup Defaults | Starter Stream, sample Library, suggested Ally. |
| Commitment | User declares focus/purpose/pace. |
| Intent Mirroring | Composer adapts to high-confidence behavior. |
| Momentum Bias | Onboarding/courses/reports. |
| Loading Feedback | AI generation and report composition. |
| Intentional Friction | Purchases, delete/export, sensitive actions. |
| Permission Serve | Notifications, contacts, calendar. |
| System Widget | Daily companion surface. |
| The Paywall | Paid reports and premium experiences. |
| Premium Positioning | Report artifacts and paid tiers. |

## Adapt Carefully

| Pattern | Risk |
|---|---|
| Gamified Progress | Useful if meaningful; cheap if badge-driven. |
| Variable Reward | Can become addictive. Keep it light and optional. |
| Spark Curiosity | Powerful for reports; frustrating if artificial. |
| Growth and Viral | Must emerge from pride/usefulness, not pressure. |
| Referral | Use after value, never before. |

## Dangerous / Defer

| Pattern | Reason |
|---|---|
| Contact Bridge | Privacy-sensitive and not core yet. |
| Limited Offer | Easy to damage trust with false scarcity. |
