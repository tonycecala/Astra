# Synastry perspective validation and prose thinning

## Problem
For feeling-first Synastry, accept an Ally's first name as named perspective while requiring you/your in every prose paragraph. Allow occasional direct-aspect references when they sharpen psychology; keep numeric density thresholds private as a backstop, and phrase corrective retries as qualitative thinning rather than prose quotas.

## Signals
- A report names the Ally naturally by first name in every chapter but receives `perspective_erasure` because validation requires the exact full stored name.
- The report passes evidence and acceptance checks while astrology terminology repeatedly leads or crowds the psychology.
- A corrective retry sounds mechanically optimized because it receives numeric prose quotas.

## Root Cause
- Identity validation confused an exact database label with the reader-visible way a person is normally named.
- Technical-density guidance was expressed as a writing formula rather than as a private safety boundary.

## Investigation
Compare chapter and paragraph references separately. Count second-person references per prose paragraph, Ally first-name references per chapter, technical terms, astrology-bearing paragraphs, heavy paragraphs, and astrology-led paragraphs. Read the accepted report before choosing thresholds; do not infer reader quality from a category count alone.

## Resolution
Accept the Ally's first name for chapter-level presence while requiring `you` or `your` in every prose paragraph. Tell the writer that an occasional direct aspect is welcome only when it sharpens the psychological mechanism. Keep density thresholds private and use them only to detect astrology-dominated writing.

## Prevention
Test first-name/full-name equivalence, paragraph-level second person, occasional aspect use, astrology-led openings, recurring chart commentary, and the unchanged more-than-two-fatal acceptance rule. Phrase retry feedback as qualitative thinning rather than a numeric rewrite quota.
