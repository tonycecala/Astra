# keep-long-mobile-form-actions-above-bottom-navigation

## Problem
For a long mobile choice form, keep the primary action in a compact fixed bar immediately above persistent bottom navigation. Hide the duplicate top action on phone, reserve scroll padding so final controls are not covered, dismiss the bar when confirmation opens, shorten supporting descriptions, and verify the CTA remains in the viewport after scrolling to the last required choice.
